# Mr. Whiskers' Blog

A simple, semantic HTML blog page about Mr. Whiskers, a very lovable cat. This project focuses on writing clean, accessible HTML structure.

## Features

- Header with a welcome heading, a captioned image (`figure` / `figcaption`), and a navigation menu
- In-page navigation using anchor links (`#about`, `#posts`, `#contact`)
- **About** section introducing Mr. Whiskers and the blog
- **Posts** section with three `article` entries
- **Contact** section in the footer with a clickable phone number (`tel:`) and email link (`mailto:`)

## Built With

- HTML5
